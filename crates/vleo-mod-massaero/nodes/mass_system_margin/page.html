3Where the simple version breaks

It is a single fraction applied to the whole, so it says nothing about which items will grow. It is only meaningful between nothing and a half: a margin cannot be negative, and above half the design is a sketch and the number is not a budget.

No assumption stated. A multi-step relation always has at least one.

Outside 0 … 0.5 the row refuses rather than answers: a margin cannot be negative; above 50% the design is a sketch and the number is not a budget.

4Common wrong idea

It is easy to think this is the same as the allowances already added to each item for how mature its design is. It is not: it is separate from and on top of them.
