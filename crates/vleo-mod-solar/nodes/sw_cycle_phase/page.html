How far through its solar cycle is the mission epoch?

phase(T) = (T - start_of_cycle) / mean_cycle_length

Source noaa_swpc — NOAA Space Weather Prediction Center — solar and geomagnetic indices NOAA, retrieved 2026-09-01

Zero at the cycle's start and one at its end. This is the row the whole cycle-dependent half of the subsystem turns on: at the declared epoch it is 0.619, which is past maximum on the declining side — the storm-rich phase.

A design does not need to know which cycle it flies in so much as WHERE in one. Activity is a strong function of phase and a much weaker function of which cycle is being lived through, which is what makes a phase-indexed climatology possible at all. The difficulty in the relation is not the definition, which is a division. It is that the current cycle has not finished, so the denominator does not exist yet — and every consequence of this row follows from which length is put there in its place.

  1. Define the phase as the fraction of a cycle elapsed — zero at the opening minimum, one at the next. It needs two things the row must get from somewhere: a start and a length.phase(T) = (T - start) / length
  2. The start is not a problem. The published boundaries give cycle 25 an opening of 2019-12-01, day 7274, and the epoch is 2588 days past it.T - start = 9862 - 7274 = 2588 d
  3. The length is the problem, and it is worth being explicit about why. solar_cycles.csv gives cycle 25 an end of 2025-12-15 and a length of 6.04 years, and both are artefacts of where the RECORD stops rather than where the cycle stops. Taking that length at face value puts the epoch past the end of its own cycle and the row would refuse a date that is only a year beyond the archive.2588 / (6.04 * 365.25) = 1.17 — above the declared bound of 1
  4. The two COMPLETE cycles in the table ran 11.88 and 11.00 years. Their mean is the only length the record supports for a cycle that has not ended, and it is what the study's own meanCycleAt folds with beyond its last cycle, so using it is a port rather than an invention.L = (11.88 + 11.00) / 2 = 11.44 yr = 4178.46 d
  5. WHICH of the table's two accounts of a length is used has to be stated, because solar_cycles.csv publishes both and they disagree. The length_years column is printed to two decimals and averages 4178.46 days; the boundaries those lengths came from differ by 4338 and 4017 days, which average 4177.50. This row folds with the published column — the study's own number — and the 0.96-day gap moves the epoch's phase from 0.619509 to 0.619367. That is far below anything downstream can resolve, and it is a choice rather than a rounding, so it is written down.published: 4178.46 d -> phase 0.619367 · boundaries: 4177.50 d -> 0.619509
  6. Which puts the declared epoch a little past the middle of its cycle, on the declining side — the storm-rich part, and the same part of the cycle the exceedance rows independently point at.phase = 2588 / 4178.46 = 0.6194
  7. The bound at one is load-bearing rather than tidy. Dividing by a mean instead of the truth means a date far enough out returns a phase above one, and a phase above one says the date belongs to a cycle this row cannot name. Refusing is the only honest answer available: folding round would report an early-cycle phase for a date whose cycle number nothing in the data fixes.

Reading the answer

0.6194 is not 61.9 per cent of anything physical. The cycle is not symmetric: the phase-stacked mean F10.7 climbs from 72 sfu at phase 0.025 to 165 at 0.425 and then takes twice as long to fall back to 68, so equal steps in phase are not equal steps in activity and the number cannot be read as a proxy for one. sw_mean_cycle_level is the row that converts. The answer also inherits the guess about cycle 25's length in full: if 25 runs longer than 11.44 years this phase is too large and the design is being sized against a quieter part of the cycle than it will meet.

Guards

  • phase ≥ 0 — a phase is a fraction of the way through a cycle and cannot be negative. A negative value means the epoch precedes the cycle it was assigned to
  • phase ≤ 1 — one is the end of the cycle. Above it the epoch belongs to the next cycle, and this row cannot name it because the record does not contain its start — so it refuses instead of folding round silently
