3Where the simple version breaks

It is a new array in full sun at an average angle, so it leaves out eclipse, ageing and heat. It uses the solar constant, one fixed figure for sunlight. Above 50 kilowatts the array is not the one these inputs describe.

No assumption stated. A multi-step relation always has at least one.

Outside 0 … 50000 W the row refuses rather than answers: array output cannot be negative; above 50 kW the array is not the one described by these inputs.
