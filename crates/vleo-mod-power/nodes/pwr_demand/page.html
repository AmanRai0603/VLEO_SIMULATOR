3Where the simple version breaks

It counts these five loads and the harness loss and nothing else. It is written with each load named, so a forgotten one shows up as a missing part, but a load nobody named is still missed. Above 50 kilowatts nothing in this mass class supplies it.

No assumption stated. A multi-step relation always has at least one.
