## Builds

1. **The chain checked when today's design is built.** A release whose seal
   does not check through the chain is refused like any other, with the
   reason, and its group's last good release taken in its place, marked.
   `/v1/today` and Explore say who sealed each release taken.
2. **The base version shown:** the design's own, and each release's base
   (`base_version`, F1). "N releases behind" waits for 1.1.
3. **Results kept** from Explore, each naming the design, its fingerprint and
   the engine that made it (phase A already writes these; Explore keeps and
   lists them).
4. **Raise issue** from any red mark: an issue file written into `issues/`,
   addressed to a group and a node, with the evidence (W11, first half).
5. **Removed:** today's tool page's layer, run, inputs and results views,
   which Explore now holds; the readers' folder and `xtask readers`
   (decision 1). Their tests and CI jobs go with them, and nothing that a
   remaining test reads is lost.
