## In one line

How far the published scale under-reads the worst three-hour stretch of a day when it is fed the day's average geomagnetic activity.

## Said simply

How far the published scale under-reads the worst three-hour stretch of a day when it is fed the day's average geomagnetic activity. It is a correction to add, measured on the record, because the atmosphere responds to the disturbance it actually met, which for a heating calculation is closer to the day's peak than its average.

## Picture it

Think of a day's average wind speed and its strongest gust. A scale built for gusts, fed the day's average, will always read lower than the worst gust that actually blew. This row measures how much lower, at each level of activity, so a design can add it back.

## Where it breaks

It is a median for each band of activity, so it describes the typical day and misses any particular one; a worst case would need a percentile, which is not published here. Above a daily activity of 110 the correction rests on only twenty days, and its drop there may be a small-sample accident.

## Common misreading

That this correction also fixes the day's average slot. The average slot has its own bias of the opposite sign, running from +0.042 down to -0.487, so using this one there would double the error rather than remove it.
