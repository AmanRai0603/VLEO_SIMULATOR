## Where it breaks

The margin of 1.28 spreads is really a 90th-percentile edge while the run is labelled 95 per cent. At that margin the band in fact holds a little more than a normal curve would say, but the far tail is heavier than normal, so a 99 per cent band built the same way would fall short. One spread is used for the whole window.

## Common misreading

It is easy to take this for the existing single flux design value. That one adds a drift from today's value; this adds how wrong the pattern is about the window, and they answer different questions.
