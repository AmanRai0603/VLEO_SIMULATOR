## In one line

Which Kp reading the design is driven by, the day's mean of its eight three-hour slots or its worst slot, and that choice has not been made yet: the sheet says it needs a person.

## Said simply

Kp is graded every three hours, so each day has eight readings. The solar group publishes two of them for each scenario, the typical one and the worst one, and this row is where somebody decides which one the design is built on. It is empty on purpose: no value has been chosen, and an assistant may not choose one.

## Picture it

Think of designing a roof gutter for a stormy day. You could size it for the day's average rain or for its heaviest hour; both are true facts about the same day, but which one you build to is a decision, not a measurement. This row is that decision for the Sun's magnetic storms, and it is still open.

## Where it breaks

There is no value yet, so there is no simple version to break. The sheet names three defensible answers: the mean, which the legacy run used and a daily-averaged density model wants; the peak, which is what a vehicle actually meets; or both, sized on the mean and closed against the peak, which would make this row a set rather than a switch.

## Common misreading

That the legacy run has already settled it. Its header says the mean slot, so the study answered this for its own run, but the sheet records that as evidence rather than a recommendation and asks for the choice to be made, not defaulted.
